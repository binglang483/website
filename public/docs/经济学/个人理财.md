# 个人理财入门

> 从月光到财务自由的思维转变

## 财富管理基础

### 记账 → 预算 → 储蓄 → 投资

### 紧急储备金

建议 3-6 个月生活费，放货币基金随时可取。

## 资产配置

### 四大账户

| 账户 | 用途 | 配置 |
|------|------|------|
| 现金账户 | 日常开销 | 货币基金 |
| 保障账户 | 保险 | 重疾/意外/医疗 |
| 投资账户 | 长期增值 | 股票/基金/房产 |
| 传承账户 | 遗产 | 信托/年金 |

### 配置原则

不要把鸡蛋放在一个篮子里。年轻偏股、年长偏债。

## 基金投资

### 常见类型

| 类型 | 特点 |
|------|------|
| 货币基金 | 活期替代品，年化 2% 左右 |
| 债券基金 | 稳健收益，年化 4-6% |
| 股票基金 | 高风险高收益 |
| 指数基金 | 低成本、被动管理，推荐新手 |
| ETF | 场内交易、费用低 |

### 定投策略

固定时间固定金额买入，平滑波动。适合指数基金。

## 风险管理

### 保险配置

- 先大人后小孩
- 先保障后理财
- 定期寿险 + 重疾险 + 意外险 + 医疗险

### 负债管理

- 高息负债（信用卡分期）优先还清
- 低息负债（房贷）可慢慢还
- 不盲目加杠杆
