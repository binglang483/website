# 宏观经济学基础

> 理解经济运行的大图景

## GDP

### 三种核算方法

- **支出法**: GDP = C + I + G + NX（消费+投资+政府购买+净出口）
- **收入法**: 工资 + 利息 + 租金 + 利润
- **生产法**: 各部门增加值之和

### 潜在 GDP

经济在充分就业时的产出水平。实际 GDP 围绕潜在 GDP 波动。

## 通货膨胀

### 度量指标

- CPI（消费者物价指数）
- PPI（生产者物价指数）
- GDP 平减指数

### 成因

- 需求拉动（总需求 > 总供给）
- 成本推动（原材料/工资上涨）
- 货币超发

### 影响

- 债权人受损、债务人受益
- 固定收入者受损
- 不确定性增加

## 货币政策

### 三大工具

1. **公开市场操作**: 买卖政府债券
2. **法定准备金率**: 调整银行准备金要求
3. **再贴现率**: 调整央行对商业银行贷款利率

### 传导机制

```
央行降准 → 银行可贷资金增加 → 利率下降 → 投资/消费增加 → GDP ↑ + 通胀 ↑
```

## 财政政策

### 自动稳定器

累进税、失业保险、农产品价格支持 — 经济好时自动收紧、差时自动刺激。

### 相机抉择

政府主动调整支出和税率。但存在时滞（认识时滞、决策时滞、执行时滞）。

## 经济周期

繁荣 → 衰退 → 萧条 → 复苏 → 繁荣...
