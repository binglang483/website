# 逻辑思维

> 清晰思考 · 理性决策 · 有效表达

## 核心工具

### 演绎推理

大前提 → 小前提 → 结论。注意大前提是否正确。

### 归纳推理

从特殊到一般。样本量要足够大才能可靠。

### 类比推理

A 像 B，所以 A 也有 B 的某种属性。启发思考但不保证正确。

## 常见逻辑谬误

| 谬误 | 说明 |
|------|------|
| 诉诸权威 | "XX 专家都这么说" ≠ 正确 |
| 诉诸情感 | 用情绪代替论证 |
| 稻草人 | 歪曲对方观点后反驳 |
| 以偏概全 | 样本不足就下结论 |
| 循环论证 | 用结论证明结论 |
| 非黑即白 | 只给两个选项忽略中间 |
| 事后归因 | B 发生在 A 之后 → A 导致 B |
| 诉诸无知 | 没证据证明错 → 就是对的 |

## 批判性思维

### 提问清单

1. 结论是什么？
2. 理由是什么？
3. 证据可靠吗？
4. 有没有其他解释？
5. 有没有遗漏的重要信息？

## 结构化思考

### 金字塔原理

中心思想 → 分论点 → 论据支撑。上统下、下支撑上。

### MECE

相互独立、完全穷尽。拆解问题时不重不漏。
