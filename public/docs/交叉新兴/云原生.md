# 云原生

> 容器 · 微服务 · DevOps — 云计算时代的应用构建方式

## 四大支柱

1. **容器化**: Docker / containerd / runC
2. **微服务**: 独立部署、松耦合
3. **DevOps**: CI/CD 自动化流水线
4. **持续交付**: 频繁可靠发布

## CNCF 云原生全景图

- **编排**: Kubernetes
- **服务网格**: Istio / Linkerd
- **监控**: Prometheus + Grafana
- **日志**: ELK / Loki
- **追踪**: Jaeger / SkyWalking
- **CI/CD**: ArgoCD / Tekton / GitLab CI
- **Serverless**: Knative

## 服务网格

```
数据平面 (Envoy Sidecar):
├── 流量管理（路由、负载均衡、故障注入）
├── 可观测性（指标、日志、分布式追踪）
├── 安全（mTLS 加密、认证授权）
└── 策略执行

控制平面 (Istio):
├── Pilot → 流量管理
├── Citadel → 证书管理
├── Galley → 配置验证
└── Mixer → 遥测收集
```

## GitOps

用 Git 仓库作为基础设施单一事实来源：
- ArgoCD 自动同步 Git → K8s 集群
- 变更通过 PR Review + CI 自动化
- 可回滚、可审计
