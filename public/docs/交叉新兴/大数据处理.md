# 大数据处理

> 海量数据的采集 · 存储 · 计算 · 分析

## 核心特征 (4V)

- Volume（数据量大）
- Velocity（产生速度快）
- Variety（类型多样：结构化/半结构化/非结构化）
- Value（价值密度低但总价值高）

## Lambda 架构

```
                    ┌──────────┐
数据流入 ─────────→│ Batch层  │→ 全量离线计算 → 批处理视图
     │             └──────────┘
     │             ┌──────────┐
     └────────────→│ Speed层  │→ 增量实时计算 → 实时视图
                   └──────────┘
                                ↓ 合并
                          ┌─────────┐
                          │ Serving │ → 查询接口
                          └─────────┘
```

## 技术栈

### 数据采集

- Flume / Logstash（日志收集）
- Kafka（消息队列缓冲）
- Sqoop / DataX（数据库导入）

### 计算引擎

| 引擎 | 特点 |
|------|------|
| Hadoop MapReduce | 离线批处理 |
| Spark | 内存计算、通用 |
| Flink | 流处理、精确一次语义 |
| Presto/Trino | 交互式查询 |

### 存储

| 系统 | 特点 |
|------|------|
| HDFS | 分布式文件存储 |
| HBase / Cassandra | 宽列 NoSQL |
| ClickHouse | 列式 OLAP |
| Elasticsearch | 搜索 + 分析 |
| Iceberg / Delta Lake | 数据湖表格式 |
