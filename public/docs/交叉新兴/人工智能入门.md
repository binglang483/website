# 人工智能入门

> AI 基础 — 从机器学习到大语言模型

## 发展历程

```
图灵测试(1950) → 专家系统(80s) → 统计学习(90s) → 深度学习(2012 AlexNet) → Transformer(2017) → LLM(2022+)
```

## 机器学习分类

| 类型 | 数据 | 目标 | 示例 |
|------|------|------|------|
| 监督学习 | 有标签 | 预测 | 分类、回归 |
| 无监督学习 | 无标签 | 发现结构 | 聚类、降维 |
| 强化学习 | 奖励信号 | 策略 | AlphaGo、自动驾驶 |
| 半监督 | 少量标签 | 利用未标注 | 图像分类 |

## 经典算法

### 监督学习

- **线性回归/逻辑回归**: 基线模型、可解释
- **决策树/随机森林/XGBoost**: 表格数据王者
- **SVM**: 小样本高维数据
- **KNN**: 简单惰性学习

### 无监督学习

- K-Means 聚类
- PCA 主成分分析
- DBSCAN（密度聚类）
- t-SNE/UMAP（降维可视化）

## 深度学习

### 神经网络基础

- **CNN**: 图像识别（ResNet、EfficientNet）
- **RNN/LSTM/GRU**: 序列建模（已基本被 Transformer 替代）
- **Transformer**: Attention 机制，NLP/CV/多模态通吃

### Transformer 架构

```
Encoder: Self-Attention → FFN → Add&Norm × N
Decoder: Masked Self-Attention → Cross-Attention → FFN → Add&Norm × N
核心: Scaled Dot-Product Attention
  Attention(Q,K,V) = softmax(QKᵀ/√dₖ) V
```

## 大语言模型

### 训练三阶段

1. **预训练**: 海量文本自监督学习（next token prediction）
2. **SFT**: 高质量指令数据微调
3. **RLHF**: 人类反馈强化学习对齐偏好

### 推理加速

- KV Cache
- Quantization (INT4/INT8)
- Tensor Parallelism / Pipeline Parallelism
- Speculative Decoding

## 评估指标

### 通用

准确率、精确率、召回率、F1 Score、ROC-AUC

### 生成模型

BLEU（N-gram 匹配）、ROUGE（召回导向）、HumanEval（代码）、MMLU（知识）
