# 渗透测试

> Penetration Testing · 主动模拟攻击者，检验安全防线

## 什么是渗透测试

渗透测试（Pentest）是授权的安全评估过程——模拟真实攻击者的技术和方法，对目标系统进行入侵尝试，发现潜在的安全弱点。

**红队 = 攻击者视角** → **蓝队 = 防守者视角**

## 渗透测试类型

| 类型 | 说明 | 信息级别 |
|------|------|----------|
| 黑盒测试 | 不了解内部结构，只有目标域名 | 最少 |
| 白盒测试 | 完全了解内部结构 | 最多 |
| 灰盒测试 | 部分了解内部信息 | 中间 |
| 物理渗透 | 模拟入侵机房/办公区 | - |
| 社会工程 | 模拟钓鱼、电话诈骗 | - |
| 无线渗透 | 测试 WiFi、蓝牙安全 | - |

## 标准流程

### PTES（渗透测试执行标准）

```
1. 前期交互 (Pre-engagement Interactions)
   └── 确认范围、目标、时间、授权

2. 情报收集 (Intelligence Gathering)
   ├── 被动: WHOIS, DNS, Google Hacking
   └── 主动: 端口扫描、指纹识别

3. 威胁建模 (Threat Modeling)
   └── 攻击面分析、攻击树构建

4. 漏洞分析 (Vulnerability Analysis)
   └── 扫描器 + 手工验证

5. 渗透攻击 (Exploitation)
   └── 漏洞利用、获取初始访问

6. 后渗透 (Post Exploitation)
   ├── 权限提升
   ├── 横向移动
   └── 数据访问验证

7. 报告撰写 (Reporting)
   └── 风险分级 + 修复建议
```

## 信息收集

### 被动信息收集

```bash
# DNS 查询
nslookup target.com
dig target.com any
host target.com

# 子域名枚举
# subfinder -d target.com
# amass enum -passive -d target.com

# WHOIS / 注册信息
whois target.com

# 证书透明度日志 → 子域名
# https://crt.sh/?q=target.com

# Google Hacking
site:target.com filetype:pdf
inurl:target.com admin
site:target.com "password"
cache:target.com

# Shodan (扫描器结果数据库)
hostname:target.com
product:Apache target.com
```

### 主动信息收集

```bash
# 端口扫描
nmap -sn 192.168.1.0/24          # 主机发现
nmap -sV -p 1-65535 target.com   # 全端口+版本
nmap -O target.com               # 操作系统识别
nmap --script vuln target.com     # 漏洞脚本

# 目录扫描
# gobuster dir -u http://target.com -w wordlist.txt
# dirsearch -u http://target.com

# Web 指纹
whatweb http://target.com
wappalyzer (浏览器插件)
builtwith.com
```

## 常用攻击向量

### 1. 弱口令

```
目标: SSH, RDP, Web Login, VPN, MySQL, FTP

工具:
- Hydra (通用爆破)
- Medusa (多线程)
- CrackMapExec (SMB)
- patator (灵活)

示例:
hydra -l admin -P rockyou.txt ssh://192.168.1.1
hydra -L users.txt -p admin http-post-form "/login:user=^USER^&pass=^PASS^:失败提示"
```

### 2. 未授权访问

```
常见:
├── GitLab / Jenkins / Grafana 默认账号
├── Nacos 默认 nacos/nacos
├── Spring Boot Actuator
├── K8s Dashboard 未认证
├── MongoDB / Redis 无密码
├── phpMyAdmin root/空
└── 管理后台 default admin/admin
```

### 3. 版本漏洞

```
2024 经典:
├── Apache Log4j2 (CVE-2021-44228)
├── Spring Cloud Gateway (CVE-2022-22947)
├── Shiro 反序列化 (rememberMe)
├── Jenkins 反序列化 (CVE-2015-8103)
├── Weblogic (T3 反序列化)
├── Fastjson 1.2.x
├── Struts2 (S2-0xx)
└── Ghostscript / ImageMagick 任意文件读写
```

### 4. 内网横向移动

```
方法:
├── SMB 永恒之蓝 (EternalBlue/MS17-010)
├── WMI 远程执行
├── PsExec / WMExec
├── Pass-the-Hash (LM Hash)
├── Kerberoasting (TGS Hash)
├── DCSync (域控导出)
├── PSExec / Impacket 套件
└── WinRM (端口 5985/5986)

工具: PowerSploit, Empire, Cobalt Strike, Mimikatz
```

## 权限提升

### Windows 提权

```
检查清单:
□ whoami /priv → 特殊权限
□ systeminfo → HotFixes (永恒之蓝)
□ ms16-032 / ms17-010 / ms18-081
□ unquoted service path
□ AlwaysInstallElevated
□ 计划任务文件权限
□ .dll 劫持
□ 注册表 Autorun
□ UAC 绕过
□ Token Impersonation

工具:
- PowerUp (PowerShell 提权枚举)
- windows-privesc-check
- Potato (Rotten/Sweet/God Potato)
- JuicyPotato (服务账户 SYSTEM)
- PrintSpoofer
```

### Linux 提权

```
检查清单:
□ uname -a → 内核漏洞
□ sudo -l → 可 sudo 的命令
□ SUID/SGID 程序
□ cron 任务
□ /etc/passwd 权限
□ .bashrc / .profile
□ NFS no_root_squash
□ Docker 容器逃逸

工具:
- LinPEAS (最常用)
- LinEnum.sh
- linux-exploit-suggester
- BeRoot
```

## 法律与伦理

⚠️ **渗透测试必须有书面授权书！**

未授权的渗透测试 = 非法入侵，违反《中华人民共和国网络安全法》《刑法》第 285/286 条。
