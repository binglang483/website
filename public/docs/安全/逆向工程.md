# 逆向工程

> Reverse Engineering · 从二进制还原源码和逻辑的艺术

## 什么是逆向工程

逆向工程是指在没有源代码的情况下，通过分析二进制程序的机器码、汇编指令和行为逻辑，还原出程序的功能、算法实现、数据结构和设计思路的过程。

**核心目标**：理解程序"做了什么"和"怎么做的"。

## 常见应用场景

- 🔐 **软件破解**：去除商业软件的授权验证、注册机制
- 🛡️ **恶意软件分析**：分析病毒、木马、勒索软件的行为
- 🔍 **协议还原**：还原私有网络协议、文件格式
- 🔧 **兼容性研究**：让老软件在新系统上运行
- 📚 **学习研究**：学习优秀软件的架构设计

## 核心技术栈

### 静态分析工具

| 工具 | 类型 | 说明 |
|------|------|------|
| IDA Pro | 反汇编器 | 业界标杆，支持 x86/ARM/MIPS |
| Ghidra | 反汇编器 | NSA 开源，内置反编译器 |
| x64dbg | 调试器 | Windows 下最流行的动态调试器 |
| Binary Ninja | 反汇编器 | 商业，有 Python API |
| radare2 | 框架 | 开源，命令行，插件丰富 |

### 动态分析工具

- **x64dbg / OllyDbg** — Windows 用户态调试
- **WinDbg** — 内核态调试，驱动分析必备
- **GDB / LLDB** — Linux / macOS 调试
- **Frida** — 动态插桩框架，无需重新编译
- **DynamoRIO** — 二进制翻译框架

## 学习路线

### 第一阶段：基础

1. **汇编语言**：x86 → x64 → ARM
2. **C/C++ 基础**：理解指针、内存布局、函数调用约定
3. **PE/ELF 文件格式**：节区、导入导出表、重定位

### 第二阶段：进阶

1. **逆向 Windows API**：熟悉常用 Win32 API
2. **调试技巧**：断点、单步、内存读写、寄存器跟踪
3. **脱壳基础**：识别常见壳（UPX、VMProtect）、OEP 定位

### 第三阶段：高级

1. **反混淆**：控制流平坦化、虚假控制流
2. **虚拟化保护**：VMProtect、Themida 的 VM 分析
3. **内核逆向**：驱动框架、SSDT Hook、内核 PatchGuard

## 常用分析方法

### 字符串搜索法

```
IDA: Search → Text String
x64dbg: 右键 → Search for → All modules → Strings
```

从错误提示、UI 文字、URL 等字符串定位关键逻辑。

### API 断点法

在关键 API 上设断点：

```
CreateFileW       — 文件操作
RegOpenKeyExW     — 注册表
InternetOpenUrlW  — 网络请求
CryptDecrypt      — 解密操作
```

### Hook 法

用 Frida / Detours 拦截函数调用：

```javascript
// Frida 示例：拦截 MessageBoxA
Interceptor.attach(Module.findExportByName('user32.dll', 'MessageBoxA'), {
  onEnter(args) {
    console.log('Text:', args[1].readCString())
  }
})
```

## 注意事项
