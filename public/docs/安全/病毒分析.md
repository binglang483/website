# 病毒分析

> Malware Analysis · 理解恶意软件行为，构建防御能力

## 分析方法分类

| 方法 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| 静态分析 | 不运行，只看代码 | 安全，看整体逻辑 | 遇到加壳/混淆困难 |
| 动态分析 | 在沙箱中运行 | 能看到真实行为 | 可能漏行为、被反分析 |

## 静态分析流程

### 1. 文件信息收集

```bash
# 基本信息
file virus.exe
md5sum virus.exe
sha256sum virus.exe

# PE 信息
pescan virus.exe
pe-bear.exe virus.exe

# 查 VirusTotal
# 上传或 API 查询社区检测结果
```

### 2. 壳识别

```
常见壳特征:
├── UPX       → 节名 UPX0/UPX1, PUSHAD/POPAD
├── Themida   → 节名 .themida, 运行自解密
├── VMProtect → 节名 .vmp0/.vmp1, VM 虚拟化
├── Packer    → Import 很少, Entropy 很高
└── .NET Protector → .NET 平台混淆
```

**Entropy 检测**：
```python
import math
import collections

def entropy(data):
    counter = collections.Counter(data)
    length = len(data)
    return -sum((c/length) * math.log2(c/length) for c in counter.values())

# 熵 > 7.0 通常意味着加壳或加密
print(entropy(open('virus.exe', 'rb').read()))
```

### 3. 字符串分析

```bash
# 提取可读字符串
strings -n 4 virus.exe

# 重点关注:
# - URL / IP 地址 (C2 服务器)
# - 注册表路径 (持久化位置)
# - 文件路径 (释放文件)
# - PowerShell / cmd 命令
# - 互斥体名 (多开检测)
```

### 4. 导入表分析

关键导入 API：

| API | 含义 |
|-----|------|
| InternetOpenUrl | 网络通信 |
| CreateProcess | 启动新进程 |
| OpenSCManager | 服务操作 |
| RegSetValue | 注册表写入 |
| SetWindowsHookEx | Hook 注入 |
| VirtualAlloc | 内存操作 |
| CryptEncrypt | 加密 |

## 常见恶意行为

### 持久化技术

```
1. 注册表 Run 键
   HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run

2. 计划任务
   schtasks /create /tn "Updater" /tr "virus.exe"

3. 服务注册
   sc create BadSvc binPath="virus.exe" type=own

4. Winlogon Shell 扩展
   HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon

5. DLL 劫持
   在目标程序目录放同名 DLL

6. WMI 事件订阅
   通过 WMI 事件触发执行

7. 启动文件夹
   C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp
```

### C2 通信

```
协议类型:
├── HTTP(S)  → 最常见，走正常 80/443
├── DNS      → 隧道通信，隐蔽性强
├── SMTP     → 邮件外传
├── IRC      → 传统僵尸网络
├── WebSocket → 现代浏览器劫持
└── ICMP     → 极隐蔽，利用 ping

常见 C2 框架:
- Cobalt Strike (商业)
- Metasploit
- Covenant (.NET)
- Sliver (Go)
- Brute Ratel (红队)
```

### 对抗分析

| 技术 | 原理 |
|------|------|
| 反调试 | IsDebuggerPresent, CheckRemoteDebuggerPresent |
| 反虚拟机 | 检查 MAC 地址、进程名、注册表 |
| 反沙箱 | 检测 Sleep 是否被 hook、鼠标行为 |
| 时间延迟 | 延迟几分钟后执行 |
| 条件触发 | 特定用户/时间/国家才激活 |
| 字符串加密 | 运行时解密 API 名称 |
| 多线程 | 在新线程中执行恶意代码 |

## 报告模板

```
=== 恶意软件分析报告 ===

样本信息:
  - SHA256: xxxx
  - 类型: EXE / DLL / DOCM / JS
  - 编译时间: 2024-xx-xx
  - 壳: UPX / Themida / 无

行为分析:
  1. 释放文件:
     - C:\Users\xx\AppData\Local\temp\xxx.dll
  2. 注册表:
     - HKLM\...\Run → "xxx.exe"
  3. 网络:
     - Connect: 192.168.1.100:8080 (C2)
  4. 进程:
     - 注入 svchost.exe

IOC (威胁情报):
  - IP: 192.168.1.100
  - Domain: evil.com
  - Mutex: Global\BadMutex_1234
  - Hash: aa11bb22...

处置建议:
  - 断网隔离主机
  - 删除持久化项
  - 全盘查杀
```
