# 漏洞利用

> Exploit Development · 发现漏洞后，构建可用的攻击载荷

## 核心概念

**Exploit** = 利用漏洞的代码/脚本，分为：

| 类型 | 说明 | 示例 |
|------|------|------|
| RCE | 远程代码执行 | 通过网络触发 |
| LPE | 本地权限提升 | 普通用户 → 管理员 |
| DoS | 拒绝服务 | 让目标崩溃 |
| 信息泄露 | 读取敏感数据 | 获取密码、Token |

## 缓冲区溢出利用

### 基础栈溢出

```
[高地址]
  ┌──────────┐
  │  ret addr │ ← 攻击者控制
  ├──────────┤
  │ saved ebp│
  ├──────────┤
  │  buf[64] │ ← 溢出覆盖上方
  └──────────┘
[低地址]
```

**步骤**：
1. 溢出覆盖 ret addr
2. ret addr 指向 Shellcode / ROP Chain
3. 劫持控制流

### ROP 链（Return-Oriented Programming）

当 DEP 开启时，不能直接执行栈上的 shellcode。改用现有代码片段拼接：

```
ROP Chain 示例 (x86-64):
┌─────────────────────┐
│ pop rax; ret         │ ← gadget 1
│ 0x3b (sys_execve)   │
├─────────────────────┤
│ pop rdi; ret         │ ← gadget 2
│ "/bin/sh" 地址       │
├─────────────────────┤
│ pop rsi; ret         │ ← gadget 3
│ 0                    │
├─────────────────────┤
│ pop rdx; ret         │ ← gadget 4
│ 0                    │
├─────────────────────┤
│ syscall              │ ← gadget 5
└─────────────────────┘
```

**工具**：ROPgadget, pwntools, pwndbg

### Shellcode 生成

```python
from pwn import *

# x86-64 execve("/bin/sh", 0, 0)
shellcode = shellcraft.amd64.linux.execve('/bin/sh', 0, 0)
print(asm(shellcode))
```

## Web 漏洞利用

### SQL 注入进阶

#### 时间盲注

```sql
-- 利用 SLEEP 判断条件真假
SELECT IF(1=1, SLEEP(3), 0)  -- 等3秒
SELECT IF(1=2, SLEEP(3), 0)  -- 不等
```

#### 联合注入

```sql
UNION SELECT 1,2,3,4,5--
UNION SELECT 1,user(),database(),version(),5--
```

#### 堆叠注入

```sql
-- MySQL 支持多语句
1; DROP TABLE users--
1; CREATE TABLE new AS SELECT * FROM users--
```

## 现代防御与对抗

### ASLR 绕过

- **信息泄露**：先泄露模块基地址，再计算偏移
- **部分覆盖**：低 2 字节可预测
- **ROP 利用**：同一模块内 gadget 不变

### Stack Canary 绕过

- **格式化字符串**：`%15$x` 读取 canary 值
- **字节爆破**：逐字节猜测 canary
- **Off-by-one**：覆盖 canary 最低字节

### Control Flow Integrity (CFI)

- **前向 CFI**：检查间接调用目标是否是合法函数起点
- **后向 CFI**：检查 ret 地址是否是 call 指令之后
- **绕过思路**：JOP、Data-Oriented Programming

## Exploit 开发流程

```
1. 漏洞分析  →  理解漏洞原理
2. 环境搭建  →  复现环境，开启调试
3. 偏移计算  →  找控制 ret 的偏移量
4. 构造载荷  →  ROP Chain / Shellcode
5. 触发利用  →  发送恶意输入
6. 获取 Shell →  建立交互连接
7. 编写 PoC  →  可复用的完整脚本
```

## 常用工具

- **pwntools** — Python CTF 框架，最流行
- **pwndbg** — GDB 插件，堆、ROP、Canary 可视化
- **GDB + gef** — 另一个 GDB 增强插件
- **Angr** — 符号执行引擎，自动找利用路径
- **Ropper** — ROP gadget 搜索
- **msfvenom** — Metasploit Payload 生成

## 学习路径

### CTF → 实战

- **Pwn** 方向：从 ret2win → ret2libc → ROP → 堆利用
- **Web** 方向：SQLi → XSS → 文件上传 → 反序列化
- **Misc**：隐写、流量分析、逆向
