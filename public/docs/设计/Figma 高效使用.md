# Figma 高效使用

> 从入门到精通 — 协作式设计工具全指南

## 核心概念

### 组件体系

Component → Instance → Variant 属性 → Component Set

### Auto Layout

类似 CSS Flexbox，设置方向/间距/对齐，子元素设 Constraints。

## 实用快捷键

| 操作 | macOS |
|------|-------|
| 创建组件 | Cmd+Option+K |
| 复制/粘贴样式 | Cmd+Option+C / V |
| Dev Mode | Shift+D |

## 插件推荐

Figma Tokens（设计 Token）、Iconify（图标）、Unsplash（占位图）、Stark（对比度）

## Dev Mode

自动生成 CSS/Android/iOS 代码，Code Connect 关联设计组件与实际代码。
