# UI/UX 设计原则

> 用户体验驱动设计 — 从认知心理学到像素级对齐

## 尼尔森十大可用性原则

| # | 原则 |
|---|------|
| 1 | 系统状态可见 |
| 2 | 系统匹配现实 |
| 3 | 用户控制与自由（撤销/重做） |
| 4 | 一致性与标准 |
| 5 | 错误预防优于错误提示 |
| 6 | 识别而非回忆 |
| 7 | 灵活与高效（新手简单、专家有快捷键） |
| 8 | 美学与极简 |
| 9 | 容错性（具体、建设性的错误提示） |
| 10 | 帮助与文档 |

## 视觉设计

### 色彩体系

- 互补色：强烈对比
- 同类色：和谐统一
- 中性色 + 强调色：现代简约

### 排版层级

正文字号 × 1.5 到 × 1.6 作为行高，标题 -0.02em 字间距。

### 间距系统

4px · 8px · 12px · 16px · 24px · 32px · 48px — 用一致的间距单位构建节奏感。

## 导航模式

- 顶部水平导航（7±2 项最佳）
- 侧边导航（层级深、项多时）
- 底部 Tab Bar（移动端 4-5 项）

## 设计系统

### 设计 Token

统一管理 color/spacing/radius/shadow 等变量，贯穿 Figma → 代码。

### 可访问性 (A11Y)

- WCAG 2.1 AA：对比度 ≥ 4.5:1
- 所有功能可通过键盘访问
- 表单必须关联 label
