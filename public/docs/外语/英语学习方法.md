# 英语学习方法论

> 从零基础到流利沟通的系统路径

## 核心原则

- **大量可理解输入**（i+1 理论）
- **高频重复 > 完美一次**
- **听说领先**，读写跟进
- **沉浸式环境**比死记硬背有效

## 词汇量目标

| 水平 | 词汇量 | 对应 |
|------|--------|------|
| 入门 | 1000 | 日常基本交流 |
| 初级 | 3000 | 四级 |
| 中级 | 5000-6000 | 六级/考研 |
| 高级 | 10000+ | 接近母语 |

## 听力训练

### 精听 vs 泛听

- 精听: 逐句听写，分析每个音素
- 泛听: 不求全懂，理解大意

### 资源推荐

- BBC Learning English（初级）
- Ted Talks（中级）
- YouTube 原生频道（高级）
- Netflix 英剧（沉浸式）

## 口语突破

### 跟读模仿 (Shadowing)

1. 选短音频（30秒-1分钟）
2. 听一句复述一句
3. 注意语音语调、连读、重音
4. 录下来对比原音

### 口语输出

- HelloTalk / Tandem（语言交换）
- 自言自语（描述所见）
- 英语角
- 跟剧配音

## 阅读技巧

### 精读

- 分析长难句结构
- 积累高频词汇
- 学习地道表达

### 泛读

- 选感兴趣的材料（小说、技术文档）
- 不查词典，猜词义
- 保持速度和量

## 写作提升

- 积累模板和句型
- 模仿范文结构
- 找母语者批改（ChatGPT iTalki）
- 每天写 100-300 词日记
