# 高效沟通

> 职场必备 — 让信息准确流动

## 核心原则

### 先结论后细节 (BLUF)

Bottom Line Up Front — 最重要的放最前面。

### 结构化表达

MECE 原则：相互独立、完全穷尽。

### 主动对齐

不确定就问，不要猜。确认理解：「我的理解是...对吗？」

## 向上沟通

### 汇报结构

1. 结论/问题是什么
2. 原因分析
3. 你的建议方案（最好 2-3 个，说清利弊）
4. 需要老板做什么决策

### 避免

- 只抛问题不给方案
- 事无巨细啰嗦不停
- 带着情绪沟通

## 跨部门沟通

- 理解对方视角和利益
- 用对方听得懂的语言
- 书面留痕（邮件/IM）
- 冲突时对事不对人

## 非暴力沟通

四步法：观察 → 感受 → 需要 → 请求。

❌ "你总是不回我消息！"（评判）
✅ "我发的消息 3 小时没收到回复，有点担心是不是被忽略了，能不能抽空回一下？"
