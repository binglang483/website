# 前端框架深度对比

> React · Vue · Angular · Svelte — 四大主流框架全方位剖析

## 框架概览

| 框架 | 发布方 | 核心特点 | 学习曲线 | 适用场景 |
|------|--------|----------|----------|----------|
| React | Meta | JSX、虚拟DOM、生态丰富 | 中 | 大型应用、企业级 |
| Vue | Evan You | 渐进式、模板语法、上手快 | 低 | 中小型、快速开发 |
| Angular | Google | TypeScript、全家桶、强约束 | 高 | 大型企业项目 |
| Svelte | Rich Harris | 编译时、无虚拟DOM、性能极致 | 低 | 性能敏感型项目 |

## React 核心概念

### JSX 与组件化

```jsx
function Welcome(props) {
  return <h1>Hello, {props.name}</h1>
}

function App() {
  return (
    <div>
      <Welcome name="Alice" />
      <Welcome name="Bob" />
    </div>
  )
}
```

### Hooks 使用原则

- 只在顶层调用 Hooks
- 只在 React 函数中调用
- `useState`、`useEffect`、`useMemo`、`useCallback` 是最常用的四个

### 状态管理方案

| 方案 | 类型 | 适用场景 |
|------|------|----------|
| useState/useReducer | 内置 | 简单本地状态 |
| Context API | 内置 | 跨组件共享 |
| Zustand | 第三方 | 轻量全局状态 |
| Redux Toolkit | 第三方 | 复杂全局状态 |

## Vue 核心优势

### 响应式原理

Vue 3 使用 Proxy 替代 Vue 2 的 Object.defineProperty，解决了以下问题：
- 能够检测对象属性的新增和删除
- 能够检测数组索引和长度的变化
- 不需要递归遍历整个对象

```js
const reactiveData = reactive({
  count: 0,
  nested: { deep: true }
})
reactiveData.newProp = 'hello'  // 新增属性也能触发响应式
```

### Composition API vs Options API

Composition API 允许按逻辑关注点组织代码，而不是按选项类型分散。多个功能模块的逻辑可以各自聚合，不再散落在 data/methods/computed 中。

## Angular 架构特点

Angular 采用严格的模块化架构，依赖内置完整的 DI 容器，适合超大型企业项目的团队协作。

## Svelte 编译时魔法

Svelte 在编译阶段将响应式转换为直接的 DOM 操作，避免了虚拟 DOM diff 的开销。

## 框架选型建议

- **小型项目**: Vue / Svelte
- **中大型项目**: React / Vue
- **超大型企业**: Angular / React + Redux
- **性能敏感**: Svelte / Preact
