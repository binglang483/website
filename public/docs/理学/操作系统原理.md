# 操作系统原理

> 进程 · 内存 · 文件 — 理解计算机如何管理资源

## 进程与线程

### 进程 vs 线程

- 进程是资源分配最小单位
- 线程是 CPU 调度最小单位
- 同一进程的线程共享地址空间

### 进程状态转换

就绪 → 运行 → 等待 → 就绪 → 终止

### 进程间通信

管道、消息队列、共享内存、信号量、Socket

## 内存管理

### 虚拟内存

给每个进程独立的 4GB 地址空间（32位），通过页表映射到物理内存。

### 页面置换算法

OPT（最佳）> LRU（最近最少使用）> FIFO（先进先出）> LFU（最不常使用）

## 死锁

四个必要条件：互斥、占有等待、不可抢占、循环等待。破坏任一即可避免。

## 文件系统

### 常见文件系统

FAT32 → NTFS → ext3 → ext4 → Btrfs → ZFS

### inode 结构

文件元数据（权限、时间、指针），目录项只存文件名 + inode 号。
