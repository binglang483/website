# 计算机网络

> 从 HTTP 到 TCP — 理解数据如何穿越千山万水

## OSI 七层模型

应用层 → 表示层 → 会话层 → 传输层 → 网络层 → 数据链路层 → 物理层

## TCP vs UDP

| 特性 | TCP | UDP |
|------|-----|-----|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠传输 | 不可靠 |
| 头部 | 20 字节起 | 8 字节 |
| 拥塞控制 | 有 | 无 |
| 适用 | 文件传输、网页 | 实时音视频、DNS |

### TCP 三次握手

SYN → SYN-ACK → ACK，确认双方收发能力正常。

### TCP 四次挥手

FIN → ACK → FIN → ACK，双方独立关闭。

## HTTP 演进

- **HTTP/1.1**: 队头阻塞、头部冗余
- **HTTP/2**: 二进制分帧 + 多路复用 + HPACK 压缩 + 服务器推送
- **HTTP/3**: 基于 QUIC（UDP），解决 TCP 层队头阻塞

## HTTPS 握手

非对称加密交换密钥 → 对称加密传输数据。证书链逐级验证根 CA 签名。

## 状态码速查

200/201/204 成功 · 301/302/304 重定向 · 400/401/403/404/429 客户端错误 · 500/502/503/504 服务器错误

## DNS 解析

浏览器缓存 → 系统缓存 → 路由器 → ISP DNS → 根服务器 → TLD → 权威 DNS
