# 数据结构与算法

> 计算机科学基石 — 从数组到图的完整知识体系

## 复杂度分析

| 复杂度 | 名称 | 典型场景 |
|--------|------|----------|
| O(1) | 常数 | 数组按下标访问 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 遍历数组 |
| O(n log n) | 线性对数 | 归并/快排平均 |
| O(n²) | 平方 | 冒泡排序 |
| O(2ⁿ) | 指数 | 递归暴力解 |

## 线性结构

### 数组 vs 链表

- 数组: 随机访问 O(1)，插入删除 O(n)
- 链表: 随机访问 O(n)，头部插入删除 O(1)

### 栈 (LIFO) vs 队列 (FIFO)

栈常用于函数调用、括号匹配、表达式求值；队列常用于任务调度、广度优先搜索。

## 非线性结构

### 二叉搜索树

中序遍历得到有序序列，平衡树保证 O(log n) 操作。

### 堆

完全二叉树，数组存储。Top K 问题用大小为 K 的堆 O(n log K)。

### 图

- 存储：邻接表（稀疏图）vs 邻接矩阵（稠密图）
- 遍历：DFS（栈/递归）vs BFS（队列）
- 最短路径：Dijkstra（非负权）、Bellman-Ford（可负权）、A*（启发式）

## 排序算法对比

| 算法 | 平均 | 空间 | 稳定 |
|------|------|------|------|
| 快排 | O(nlogn) | O(logn) | ❌ |
| 归并 | O(nlogn) | O(n) | ✅ |
| 堆排 | O(nlogn) | O(1) | ❌ |
| 插入 | O(n²) | O(1) | ✅ |
| 计数 | O(n+k) | O(k) | ✅ |

## 算法范式

- **动态规划**: 最优子结构 + 重叠子问题 + 状态转移方程
- **贪心**: 每步选当前最优
- **回溯**: 暴力枚举 + 剪枝
- **分治**: 分解 → 解决 → 合并
