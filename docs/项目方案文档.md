# 个人知识网站 - 项目方案文档

## 一、项目概述

### 1.1 项目定位
全领域知识平台，涵盖安全、开发、设计、理工、外语、经济、管理、医学、职业技能等12大领域。
支持博客发布、知识库管理、用户交流、作品展示等功能。

### 1.2 目标用户
- 个人知识管理与笔记记录
- 技术分享与学习交流
- 多领域知识体系化整理

### 1.3 核心需求
- 多端适配（PC + 移动端）
- Markdown 编辑，支持图片粘贴
- 用户系统（注册、登录、权限管理）
- 内容分类管理（12大领域 + 子分类）
- 评论系统（访客可浏览，评论需登录）
- 内容权限控制（公开/登录可见/密码）

## 二、技术架构

### 2.1 技术选型

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 前端框架 | Nuxt 3 | 3.x | Vue 3 全栈框架 |
| UI 组件 | TailwindCSS | 3.x | 原子化 CSS |
| 状态管理 | Pinia | 2.x | Vue 官方状态管理 |
| 后端框架 | Spring Boot | 3.x | Java 企业级框架 |
| 数据库 | SQLite / PostgreSQL | - | 开发用 SQLite，生产用 PostgreSQL |
| ORM | MyBatis-Plus | 3.x | 数据库操作 |
| 内容存储 | Markdown 文件 | - | 博客和知识库笔记 |
| 认证 | JWT | - | 用户认证 |

## 三、功能模块

### 3.1 用户模块

| 功能 | 说明 |
|------|------|
| 注册 | 用户名 + 邮箱 + 密码 |
| 登录 | JWT Token 认证 |
| 个人信息 | 头像、昵称、简介 |
| 权限控制 | 普通用户、管理员 |

### 3.2 博客模块

| 功能 | 说明 |
|------|------|
| 文章列表 | 分页展示，支持筛选 |
| 文章详情 | Markdown 渲染 |
| 发布文章 | Markdown 编辑器，支持粘贴图片 |
| 文章权限 | 公开/登录可见/密码保护 |
| 评论系统 | 登录后可评论 |

### 3.3 知识库模块

| 功能 | 说明 |
|------|------|
| 领域导航 | 12大领域，左侧树形导航 |
| 子分类 | 每个领域下的细分方向 |
| 笔记管理 | 创建、编辑、删除笔记 |
| Markdown 编辑 | 左右分栏，实时预览 |

### 3.4 内容存储

| 类型 | 存储方式 | 路径 |
|------|---------|------|
| 博客文章 | Markdown 文件 | content/blog/{slug}.md |
| 知识库笔记 | Markdown 文件 | content/{领域}/{子分类}/{slug}.md |
| 用户数据 | SQLite 数据库 | backend/data/app.db |
| 评论数据 | SQLite 数据库 | backend/data/app.db |

## 七、部署方案

### 7.1 本地开发

```bash
# 前端
cd frontend
npm install
npm run dev    # http://localhost:3000

# 后端
cd backend
mvn spring-boot:run    # http://localhost:8080
```

### 7.2 生产部署

```bash
# 前端构建
cd frontend
npm run build
npm run generate    # 静态生成

# 后端打包
cd backend
mvn clean package
java -jar target/knowledge-0.0.1.jar
```

### 7.3 云服务器部署（后期）

- 前端：Nginx 托管静态文件
- 后端：Systemd 服务 / Docker 容器
- 数据库：PostgreSQL
